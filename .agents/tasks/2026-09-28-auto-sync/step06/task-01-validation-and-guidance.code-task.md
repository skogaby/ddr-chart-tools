## Background

- **Why the +53 ms needs replacing.** The README's `--sync-offset-ms 53`
  advice for Ultramix → DDR World was tuned when the bias moved only the
  first tempo anchor (fixed in Step 1), so the figure is unvalidated.
  Auto-sync measures each song's actual error.
- **What the corpus is.** The Dancing Stage Unleashed rip is a flat folder
  of about 44 `<id>_all.ssq` + `<id>.wavm` pairs, plus variant charts
  (`_org_all`, `_all_<name>`) and preview loops (`_loop.wavm`), which batch
  pairing reports as unpaired.
- **What the corrections measure.** The corrections auto-sync reports are
  relative to the calibrated DDR World sync target. So they answer "how far
  is each legacy chart from DDR World sync", independently of any engine
  latency.

   `--target x86_64-unknown-linux-musl`, and record the results.

   Dancing Stage Unleashed folder for `--to-format DDR` and
