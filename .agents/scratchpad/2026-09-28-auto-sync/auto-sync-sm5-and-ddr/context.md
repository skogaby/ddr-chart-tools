## Decisions (auto mode)

- **D-a. Measurement and shifting are separate.** The orchestration helper
  is `auto_sync_delta(job, cfg, audio, charts, map) -> i32`: it measures,
  logs, and returns the delta to apply (0 in report mode or on a refusal).
  The caller then applies it with `shift_timeline`.
  - The design sketched one function taking `&mut Song` plus a separate
    `&AudioBuffer`, which the borrow checker rejects on the paths where
    the audio lives inside the song.
  - This is an internal `pub(super)` interface, and behavior is unchanged.
- **D-b. Stable log tail.**
  - `auto_sync` ∈ {`apply`, `unchanged`, `report`, `refused`}.
  - Refusals always report `refused`, whatever the mode.
  - Report mode reports the delta it would apply (0 if already in sync).
- **D-c. Refusal keys.** `Refusal::key()` in `sync/` gives the `reason=`
  labels: `no_audio`, `too_few_events`, `at_search_edge`,
  `ambiguous_peak`, `halves_disagree`, `beyond_cap`.
- **D-d. Integration tests run the real binary** and parse its stderr
  (env_logger writes there).
  - The shared helper module carries a module-level
    `#![allow(dead_code)]`, because each test crate uses a subset of it.
  - Synthetic audio is about 11 s long, to keep debug-build runs quick.
