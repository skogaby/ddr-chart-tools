## Decisions

- **L-a. Legacy SSQ inputs.** These come from the tool itself (`SM5 → DDR`
  of the synthetic song, no auto-sync). That SSQ is a valid `DDR_LEGACY`
  input: TPS 1000 with origin 0, so modernize changes nothing but its
  tempo origin bookkeeping. Real legacy files are exercised by the
  Dancing Stage Unleashed run in Step 6.
- **L-b. Undecodable passthrough bank.** Built with `xwb::parse`, then
  setting the main entry's first ADPCM predictor byte to 7 (invalid), then
  `xwb::write`. The container and format stay DDR-compliant, so
  passthrough still applies, but decoding fails.
- **L-c. One decode per job.** `legacy_to_ddr` decodes once when auto-sync
  is on and reuses that decode for re-encoding.
